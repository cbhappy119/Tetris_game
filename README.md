# Neon Tetris

一个使用 **C++17 + SFML + CMake** 制作的霓虹风俄罗斯方块游戏。

## 项目介绍

Neon Tetris 是一个桌面版俄罗斯方块小游戏，具有：

- 霓虹风格界面
- 方块预览与暂存（Hold）功能
- 计分、等级、最高分记录
- 暂停与重新开始
- 背景音乐播放

项目使用 CMake 构建，并通过 SFML 实现图形、音频与窗口交互。

## 游戏玩法

### 基本操作

- `←` `→`：左右移动方块
- `↓`：快速下落一格
- `↑` 或 `X`：旋转方块
- `Space`：硬降到底部
- `C`：暂存当前方块
- `P`：暂停 / 继续
- `R`：游戏结束后重新开始
- `Esc`：退出游戏

### 规则说明

- 方块会不断从上方落下
- 你需要通过移动和旋转，让方块完整填满一行
- 当一行被填满后会自动消除并得分
- 随着等级提升，方块下落速度会逐渐加快
- 当方块堆满到顶部时，游戏结束

## 构建与运行

### 依赖

- CMake 3.20 及以上
- C++17 编译器
- SFML 2.6.1

### 构建示例

```bash
cmake -S . -B build
cmake --build build
```

运行编译后的程序：

```text
build/NeonTetris.exe
```

## 安装包

项目提供了 Inno Setup 安装脚本：

```text
installer.iss
```

可先将编译后的发布文件整理到 `release/` 目录，再使用 Inno Setup 生成安装程序。

## 特别说明

由于版权原因，**源代码仓库中不上传背景音乐和图标文件**。

- 背景音乐文件默认不包含在源码中
- 图标文件也不包含在源码中

如果你从 `release` 中下载的是**编译后的安装包**，则它是完整的，通常已经包含：

- 背景音乐
- 图标文件
- 运行所需的程序文件和依赖

也就是说：

- **源码仓库**：只保留开发所需文件
- **release 安装包**：提供给玩家的完整可运行版本
